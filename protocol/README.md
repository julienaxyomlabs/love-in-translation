# Protocol

[Overview](../audit/README.md) · [Part A: evidence audit](../audit/evidence-audit.md) · [Part B: competing predictions](competing-predictions.md) · [Part C: study protocol](study-protocol.md) · [Corrections](../audit/corrections.md)

> [!IMPORTANT]
> **Design document only.** No participant data have been collected, no one has been recruited, no ethics application has been filed and nothing is preregistered. Every sample size, interval and threshold is a proposal. Each is to be fixed by simulation, piloting, ethics review and a Stage 1 Registered Report before any data exist.

**Relation to chapter 18.** The protocol develops the design sketched in [`paper/18-proposed-study.md`](../paper/18-proposed-study.md). It keeps that chapter's hypothesis numbers H1–H8 and adds H9 (regard beyond need fulfilment) and H10 (a predictive benchmark). Three differences are deliberate, and each is explained in Part C:

- **Which dyads are confirmatory.** Romantic couples are the confirmatory core. Parent–child dyads become confirmatory only for hypotheses whose measures pass the Korean measurement phase.
- **How safety is screened.** Each member is asked privately, and only about violence they experienced.
- **What the route split can claim.** It is reported as bounded by sensitivity analysis, never as identified.

Both documents state predictions as restrictions on the parameters of the frozen v0.2.0 equations and add no new theoretical equation. They were written against the v0.2.0 text and cite its line numbers. The v0.3.0 corrections changed the paper's wording and evidence grades but not its equations, so the predictions and the design apply unchanged.

The methods evidence behind the protocol is in [`evidence/notes/12-protocol-methods.md`](../evidence/notes/12-protocol-methods.md). It covers measures and their Korean validations, diary design, power tools, identification, ethics and Korean law.
