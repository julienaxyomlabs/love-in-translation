# Evidence

Machine-readable evidence behind the paper. Generated files are rebuilt from `paper/` by the tools named below; do not edit them by hand.

| File | Generated by | Network | Contents |
|---|---|---|---|
| `claims.jsonl` | `make claims` (`tools/extract_claims.py`) | no | every graded claim in the paper |
| `doi-verification.csv` | `make dois` (`tools/check_dois.py`) | yes | Crossref resolution of every cited DOI |
| `references.bib` | `make bibtex` (`tools/build_bibtex.py`) | yes | BibTeX for every cited DOI |
| `notes/` | — (source material) | — | the seven structured literature reviews |

## `claims.jsonl`

One JSON object per line, keys sorted, UTF-8.

| Field | Type | Meaning |
|---|---|---|
| `id` | string | `<chapter number>.<sequence>`, stable while the chapter text is unchanged |
| `chapter` | string | chapter file stem, e.g. `08-mathematical-representation` |
| `heading` | string | nearest heading above the claim |
| `grade` | enum | `established`, `moderate`, `preliminary`, `theoretical`, `hypothesis`, `assumption` |
| `tag` | string | the tag as written, e.g. `Our hypothesis, built on Moderate/mixed evidence` |
| `text` | string | the claim with Markdown stripped |
| `dois` | string[] | DOIs cited inside the claim's span |
| `kind` | enum | `prose` (text ending in a tag) or `table-row` (row of a graded table) |

A prose claim is the text between the previous tag and the current one, so a long paragraph can yield several claims. The legend table that defines the grades is excluded, and so is the "Model at a glance" summary in chapter 8, which restates claims graded in §8.4–8.10 and would otherwise count them twice.

## `doi-verification.csv`

| Column | Meaning |
|---|---|
| `doi` | the DOI as cited |
| `status` | `resolved` or `unresolved` |
| `source` | `crossref`, or `doi.org` for DOIs registered with another agency |
| `first_author`, `year`, `title` | registered metadata (year prefers print, then online) |
| `flag` | empty, `unresolved` or `metadata-mismatch` (title or first author does not match the reference text) |
| `cited_in` | chapter stems citing the DOI |

## `references.bib`

Retrieved by DOI content negotiation. Keys are normalised to `<firstauthor><year><firstword>` with letter suffixes for collisions. DOIs that return no BibTeX are listed in the file header.

## `notes/`

Structured reviews written before the paper, one per subtopic, each organised as *Takeaway / Cited findings / Inferences / Gaps* with evidence grades. They are working notes: some findings were checked against abstracts only, and where the notes and the paper differ, the paper's more conservative statement governs. They are preserved unchanged; statements superseded by later corrections are listed in [`CORRECTIONS.md`](../CORRECTIONS.md).

| Note | Scope |
|---|---|
| `01-interpersonal-processes.md` | responsiveness, support, sacrifice, gratitude, communication |
| `02-misperception-and-asymmetry.md` | accuracy, bias, attribution, giver–receiver gaps, measurement |
| `03-love-needs-compatibility.md` | love constructs, love languages, needs, attachment, trust, commitment |
| `04-safety-coercion-autonomy.md` | abuse, manipulation, psychological control, unsustainable needs, power |
| `05-family-and-culture.md` | parent–child care across cultures, provision, filial piety, social change |
| `06-korea-case-study.md` | Korean statistics and studies, with international comparisons |
| `07-formal-models-and-methods.md` | formalisms, identifiability, dyadic and longitudinal methods |
